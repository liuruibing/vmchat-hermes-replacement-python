# 数据浏览器接口文档

## 基本信息

- **基础路径**: `/api/browser`
- **请求方式**: POST
- **Content-Type**: application/json
- **响应格式**: JSON

## 通用响应结构

```json
{
  "code": 1,           // 状态码：1-成功，0-失败
  "message": "查询成功", // 响应消息
  "errorMsg": "",      // 错误信息
  "data": {}           // 响应数据
}
```

---

## 接口列表

### 1. 查询模板列表（分页）

**接口地址**: `/api/browser/templateInfo_list`

**功能说明**: 根据用户ID和查询条件分页查询模板信息，包含模板关联的基金列表

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| vcTemplateName | String | 否 | 模板名称（模糊查询） |
| vcTemplateTypes | String[] | 否 | 模板类型数组 |
| pageNum | Integer | 否 | 页码，默认1 |
| pageSize | Integer | 否 | 每页大小，默认10 |

**请求示例**:

```json
{
  "vcTemplateName": "测试模板",
  "vcTemplateTypes": ["type1", "type2"],
  "pageNum": 1,
  "pageSize": 10
}
```

**响应示例**:

```json
{
  "code": 1,
  "message": "查询成功",
  "errorMsg": "",
  "data": {
    "total": 100,
    "list": [
      {
        "vcTemplateId": "xxx",
        "vcTemplateName": "模板名称",
        "vcTemplateType": "模板类型",
        "templateByFundDtos": [
          {
            "vcFundCode": "基金代码",
            "vcFundName": "基金名称"
          }
        ]
      }
    ],
    "pageNum": 1,
    "pageSize": 10,
    "pages": 10
  }
}
```

### 14. 执行指标浏览器查询

**接口地址**: `/api/browser/index_browser`

**功能说明**: 根据模板配置和基金列表，计算并返回指标数据。支持单产品、多产品、汇总穿透等多种模板类型

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| templateId | String | 是 | 模板ID |
| templateType | String | 是 | 模板类型 |

| beginDate | String | 是 | 开始日期（yyyy-MM-dd） |
| endDate | String | 是 | 结束日期（yyyy-MM-dd） |

```json
      "fundCode": "000001",

    }

  "endDate": "2024-12-31",
  "singleBenchmark": "000300",
  "dateType": "day",
  "dateStep": "daily"
}
```

**响应示例**:

```json
{
  "code": 1,
  "message": "查询成功",
  "errorMsg": "",
  "data": {
    "000001_GJTG": [
      {
```

## 错误码说明

| 错误码 | 说明 |
|--------|------|
| 1 | 成功 |
| 0 | 失败 |

## 注意事项

1. **用户认证**: 所有接口会自动从 session/token 中获取当前用户ID，无需前端传递
2. **日期格式**: 所有日期字段统一使用 `yyyy-MM-dd` 格式
3. **数据来源**: 
   - GJTG: 国泰君安托管
   - GMJJ: 公募基金
   - ZYYX: 中信证券
   - JHLC: 计划理财
4. **模板类型**:
   - single: 单产品绩效
   - many: 多产品对比
   - gather: 汇总穿透
5. **分页参数**: pageNum 从 1 开始，不是从 0 开始

## 联调建议
