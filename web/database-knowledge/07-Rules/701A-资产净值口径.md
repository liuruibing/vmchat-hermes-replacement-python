# 业务规则：701A 资产净值口径

## 1. 规则标准文本描述
- 所有组合与计划的物理资产规模汇总，必须统一读取估值系统底层 `MFACTGZ_FUND_HLDTOTAL` 表中科目代码 **`VC_SUBCODE = '701A'`** 的 `F_PRICE` 金额。

## 2. 影响的业务指标与关联过程
- **影响指标**：计划资产净值 `F_NETVALUE`、加权日收益率的权重权重。
- **关联过程 (E2 确认)**：`DD_DW.F_PLAN_END_NETVALUE` 源码显式指定 `WHERE T.VC_SUBCODE = '701A'`。

## 3. 有效范围与注意事项
- `'701A'` 代表总资产净值金额；`'702A'` 代表单位净值单价；二者物理含义严禁混淆。
