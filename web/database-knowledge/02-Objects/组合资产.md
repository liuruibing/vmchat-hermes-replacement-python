# 业务对象：组合资产 (Portfolio Asset Scale & NAV)

## 1. 业务定义与形象类比
- **通俗类比**：
  - **701A (资产净值)**：专柜里所有货物的**总价值**（专柜资产规模）。
  - **702A (单位净值 NAV)**：专柜商品的**单价**（例如每份基金 1.0500 元）。
- **业务含义**：每日估值系统导出的底层资产规模与单价快照。

## 2. 物理关联表与字段
- **贴源表**：`DD_AODS.MFACTGZ_FUND_HLDTOTAL`
- **核心字段分组**：
  - `VC_FUNDCODE`：组合代码
  - `D_DATE`：估值核算日期
  - `VC_SUBCODE`：科目代码（`'701A'` 代表资产净值，`'702A'` 代表单位净值）
  - `F_PRICE`：科目对应金额 / 单价

## 3. 核心用途与加权机制
- **701A**：作为计划层级汇总净值的加权权重（即大资金池加权）。
- **702A**：用于单独衡量组合自身的净值涨跌幅度。
