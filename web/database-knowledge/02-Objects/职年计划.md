# 业务对象：职年计划 (Occupational Pension Plan)

## 1. 业务定义与形象类比
- **通俗类比**：相当于一家**大型连锁超市**（如“上海市职业年金计划”），是管理归集职业年金资金的最高层级业务单元。
- **业务含义**：受托或托管管理的职业年金计划实体，旗下挂载多个由不同受托人/投资管理人运营的投资组合。

## 2. 物理关联表与字段
- **主要维表**：`DD_DW.MDIM_PLAN_INFO`
- **核心字段**：
  - `VC_PLAN_LIC_ID`：计划许可编号（种子文档声称的主键候选，待 DBX 验证）
  - `VC_PLAN_CODE`：计划代码
  - `VC_PLAN_FNAME`：计划全称
  - `VC_TYPE_DETAIL`：计划类型明细（职业年金固定为 `'ZYNJ'`）
  - `D_CREATE_DATE` / `D_END_DATE`：成立与终止日期

## 3. 关联关系与关联键
- **下挂投资组合**：一个计划可下挂多个投资组合。
- **待验证 JOIN 键**：`MDIM_PLAN_INFO.VC_PLAN_LIC_ID = MDIM_FUND_INFO.VC_PLAN_CODE`（种子文档声称，具体数据库外键约束待 DBX describe 确认）。

## 4. 待确认问题与验证事项
- 详见 [`OQ-001`](../99-Inbox/Open-Questions.md#oq-001)：`VC_PLAN_LIC_ID` 与 `VC_PLAN_CODE` 在数据库中是否存在显式主外键约束。
