# 业务对象：投资组合 (Investment Portfolio / Fund)

## 1. 业务定义与形象类比
- **通俗类比**：相当于**超市里的各个独立专柜**（如“股票专柜”、“债券专柜”），是进行具体二级市场投资交易与单独资产核算的基本单元。
- **业务含义**：由投资管理人具体运营的资金组合，具有独立的组合代码、设立金额及投资管理费用率。

## 2. 物理关联表与字段
- **主要维表**：`DD_DW.MDIM_FUND_INFO`
- **核心字段**：
  - `VC_FUNDCODE`：组合代码（种子文档声称的主键候选，待 DBX 验证）
  - `VC_PLAN_CODE`：所属计划代码（待验证 JOIN 键）
  - `VC_NAME_GLR`：投资管理人名称（如“太平养老保险股份有限公司”、“易方达基金管理有限公司”）
  - `F_SET_AMOUNT`：组合初始设立金额
  - `VC_PRODUCT_INVESTMENT_TYPE`：组合投资类型枚举

## 3. 关联关系与关联键
- **归属计划**：多对一归属于某个计划。
- **待验证 JOIN 键**：`MDIM_FUND_INFO.VC_PLAN_CODE = MDIM_PLAN_INFO.VC_PLAN_LIC_ID`
- **底层估值核算**：一对多关联 `MFACTGZ_FUND_HLDTOTAL.VC_FUNDCODE`。

## 4. 待确认问题与规则注意点
- **TCZ 剔除逻辑**：`VC_NAME_GLR LIKE '太平养老保险股份有限公司%'` 是 `TCZ` 规则的真实代码过滤逻辑（详见 [`CONF-001`](../99-Inbox/Conflicts.md#conf-001)）。
- **枚举释义**：`VC_PRODUCT_INVESTMENT_TYPE` 枚举值的字典映射表待查找（详见 [`OQ-004`](../99-Inbox/Open-Questions.md#oq-004)）。
