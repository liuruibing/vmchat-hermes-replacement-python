# 业务对象：计划资产净值 (Plan Net Value / Scale)

## 1. 业务定义
- **业务含义**：单个职业年金计划在指定交易日下挂所有有效投资组合的资产净值汇总额。
- **计算逻辑**：由后台夜间存储过程 `DW_ZNST_INDEX_NEW` 汇总下属组合的 `701A` 资产净值。

## 2. 物理关联表与字段
- **大宽表**：`DD_DW.MPRF_F_PLAN_DAYNETVALUE`
- **核心字段**：
  - `VC_PLAN_LIC_ID`：计划许可编号
  - `D_DATE`：计算日期
  - `F_NETVALUE`：当日计划资产净值
  - `F_NETVALUE_TCZ`：剔除太平组合资产净值（企年硬编码写死等于 `F_NETVALUE`，详见 [`CONF-003`](../99-Inbox/Conflicts.md#conf-003)）
  - `F_NETVALUE_TCB`：剔除保留账户资产净值

## 3. 前端 SQL 汇总行规则
- 前端查询 SQL 中的 `RK = 999` 合计行采用 `SUM(F_NETVALUE)` 对全选计划直接求和。
