# 业务对象：业绩报酬 (Performance Fee & BP Impact)

## 1. 业务定义与形象类比
- **通俗类比**：
  - **受托报酬 (STBC)**：超市收取的**整体管理服务费**。
  - **投管报酬 (TGBC)**：专柜经理收取的**投资业绩提成**。
  - **业绩报酬影响 (JHBCYX)**：报酬金额占计划资产规模的比例，转化为 **BP（基点，万分比）** 表达。

## 2. 物理关联表与证券代码
- **底层持仓表**：`DD_AODS.MFACTGZ_FUND_HLDDETAIL`
- **证券代码映射（E2 确认）**：
  - **受托业绩报酬 (`STBC`)**：证券代码 `VC_SYMBOL = '221002'` 的市值 `F_PRICE` 汇总。
  - **投管业绩报酬 (`TGBC`)**：证券代码 `VC_SYMBOL = '220602'` 的市值 `F_PRICE` 汇总。

## 3. BP（基点）转化公式
$$\text{日影响率} = \frac{STBC + TGBC}{\text{前一日计划资产净值}}$$
在 SQL 展示层乘以 **10000** 转换为 BP（万分比）：
$$\text{展示值 (BP)} = \text{日影响率} \times 10000$$
例如：影响率 $0.00012 \implies 1.20\text{ BP}$。
