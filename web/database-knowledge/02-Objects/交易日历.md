# 业务对象：交易日历 (Trading Calendar / System Time)

## 1. 业务定义
- **业务含义**：管理证券市场交易日、节假日、周末及上一交易日判定的系统主时间维表。

## 2. 物理关联表与字段
- **主要维表**：`DD_DW.MDIM_SYS_TIME`
- **核心字段**：
  - `D_DATE`：公历日期
  - `F_HOLS_DAY`：是否节假日标识（`0` 代表正常交易日，`1` 代表非交易日/节假日）
  - `D_PREV_DATE`：上一交易日日期

## 3. 收益率连乘与上一日选择逻辑
- 计算收益率时，上一交易日净值必须根据 `D_PREV_DATE` 去检索离当前日期最近的上一个 `F_HOLS_DAY = 0` 的交易日。
- 交易日收益率连乘过程 `DW_ZNST_INDEX_ADD.F_PLAN_YIELD_TBZ` 依靠此表过滤节假日。
