# 业务对象：计划类型 (Plan Type)

## 1. 业务定义
- **业务含义**：用于区分年金业务线大类（如职业年金 vs 企业年金）。
- **主要类型**：
  - **`ZYNJ`**：职业年金（Occupational Pension）
  - **`QYNJ`**：企业年金（Enterprise Pension）

## 2. 物理关联表与字段
- **主要表**：`DD_DW.MDIM_PLAN_INFO`
- **核心字段**：`VC_TYPE_DETAIL`（计划类型明细编码）

## 3. 过滤逻辑与计算影响
- 在职业年金投资业绩查询 SQL 及存储过程 `DW_ZNST_INDEX_NEW` 中，必须包含过滤条件：
  ```sql
  WHERE MDIM_PLAN_INFO.VC_TYPE_DETAIL = 'ZYNJ'
  ```
- **注意**：职业年金与企业年金在 TCZ 剔除及硬编码处理上有源码级差异（详见 [`CONF-002`](../99-Inbox/Conflicts.md#conf-002) 和 [`CONF-003`](../99-Inbox/Conflicts.md#conf-003)）。
