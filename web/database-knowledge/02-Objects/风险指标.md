# 业务对象：风险指标 (Risk Metrics)

## 1. 业务定义
- **核心风险指标**：
  - **年化波动率 ($F\_VIX$)**：日收益率序列的标准差，经 $\sqrt{250}$ 年化因子放大。
  - **最大回撤 (Max Drawdown)**：选定区间内资产净值或累计收益率从峰值回落的最大幅度（14号文标准）。
  - **下行风险 (Downside Risk)**：仅对低于无风险利率的负收益做离散偏离度统计。
  - **夏普比率 (Sharpe Ratio)**：超额收益率（对比一年期定存无风险率 `104CNY`）与波动率的比值。

## 2. 物理关联表与字段
- **风险表/结果表**：`DD_DW.MMON_F_RISK_INDICATORS` / 查询 SQL 导出
- **核心字段**：
  - `F_VIX`：波动率
  - `F_MAXDOWN`：最大回撤
  - `F_SHARPE`：夏普比率

## 3. 合计行总体序列加权机制（核心避坑）
- **错误方式**：直接对各个计划的波动率取平均 `AVG(F_VIX)`（会夸大小计划对整体资金池的影响）。
- **正确步骤**：
  1. 先按各个计划每日的资产净值作为权重，加权计算出每天的“全池总体加权日收益率”；
  2. 对这个“全池总体日收益率时间序列”求样本标准差 `STDDEV()`；
  3. 乘以 $\sqrt{250}$ 进行年化处理。
