# 业务对象：资金流 (Asset Cash Flow - IN / OUT)

## 1. 业务定义与形象类比
- **通俗类比**：客户当天向专柜**存入新钱**（`IN` 申购/拨入）或**退货提现**（`OUT` 赎回/拨出）。
- **业务含义**：发生在估值核算日期的组合资金申购与赎回流水金额。

## 2. 物理关联表与字段
- **贴源流水表**：`DD_AODS.MFACTGZ_FUND_ASSETINOUT`
- **核心字段**：
  - `VC_FUNDCODE`：组合代码
  - `D_CONFIRM_DATE`：确认/核算日期
  - `VC_TYPE`：资金流向类型（`'IN'` 代表流入，`'OUT'` 代表流出）
  - `F_AMOUNT`：资金发生金额

## 3. 计算收益率时的剔除作用
在标准现金流法收益率公式中，新增资金（`IN`）不能算作投资盈利，必须从期末净值增量中扣除；拿走的资金（`OUT`）必须加回：
$$\text{真实投资纯收益} = Nav_t - Nav_{prev} - IN_t + OUT_t$$
