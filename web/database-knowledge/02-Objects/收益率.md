# 业务对象：收益率 (Yield Rate / Return Rate)

## 1. 业务定义与分类
- **标准现金流法日收益率 ($R_t$)**：剔除资金申赎干扰后，单日的真实投资收益百分比。
- **区间复利累计收益率 ($R_{cum}$)**：将选定区间内每日收益率进行几何连乘 $(1+R_1)(1+R_2)\dots(1+R_n) - 1$。
- **剔除口径收益率**：包含 TCZ（剔除太平养老组合）、TCB（剔除保留账户）、TCG（剔除归集户利息）等不同口径收益率。

## 2. 物理关联表与字段
- **加工大宽表**：`DD_DW.MPRF_F_PLAN_DAYNETVALUE` / `MPRF_PTYPE_DYIELD`
- **核心字段**：
  - `F_DP_YIELD_BZ`：标准现金流日收益率
  - `F_DP_YIELD_BZ_TCZ`：剔除太平标准现金流日收益率
  - `F_DP_YIELD_BZ_TCB` / `F_DP_YIELD_BZ_TCG`：剔除保留 / 剔除利息日收益率
  - `F_PYEILD_QJ`：区间累计收益率

## 3. SQL 对数连乘黑科技
SQL 聚合中利用对数性质将连乘转化为求和：
```sql
POWER(2, SUM(LOG(2, F_DP_YIELD_BZ + 1))) - 1
```
