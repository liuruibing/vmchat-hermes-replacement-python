# SQL 源码与算法种子分析：职年计划投资业绩

本文档整理 E1 种子文档中对标准现金流公式、对数连乘黑科技、前端 UNION ALL 合计行聚合逻辑及 5 大历史源码陷阱的分析记录。

---

## 1. 标准现金流法日收益率计算 SQL / 存储过程逻辑

- **原文结论**：每日收益率需扣除新流入资金并加回流出资金。
- **来源片段**：`DW_ZNST_INDEX_NEW.F_PLAN_DYIELD_BZ` 存储过程。
- **状态**：`confirmed`

### 逻辑推导表达式
```sql
-- 成立第一天:
R_1 = (Nav_1 - F_SET_AMOUNT) / F_SET_AMOUNT

-- 成立后续交易日 (当 Nav_prev > 0 时):
R_t = (Nav_t - Nav_prev - IN_t + OUT_t) / Nav_prev

-- 当 Nav_prev = 0 时:
R_t = 0
```

## 2. 区间复利连乘的对数 SQL 转化

- **原文结论**：针对标准 SQL 缺乏 `MULTIPLY()` 聚合函数的问题，利用对数性质将连乘转化为求和。
- **公式**：$\prod (1 + R_i) = 2^{\sum \log_2 (1 + R_i)}$
- **Oracle / DM SQL 实现片段**：
  ```sql
  POWER(2, SUM(LOG(2, F_DP_YIELD_BZ + 1))) - 1
  ```
- **状态**：`confirmed`

---

## 3. 前端查询 SQL “合计行 (RK=999)” 复合聚合机制

- **原文结论**：前端 SQL 采用 `UNION ALL` 拼接单计划明细与 `RK = 999` 的合计行。合计行并非简单 `SUM` 或 `AVG`，而是多算法混合加权。
- **来源片段**：前端查询 SQL 模板。
- **状态**：`confirmed`

### 聚合分类规则表：
1. **直接求和 (`SUM`)**：
   - 资产净值 `F_NETVALUE`
   - 受托报酬 `STBC`、投管报酬 `TGBC`
2. **期末净值加权平均**：
   - 区间单位净值增长率 `RYIELDG`
   - 剔除太平收益率 `F_PYEILD_QJ_TCTP`
   - 加权公式：`SUM(收益率 * 期末净值) / SUM(期末净值)`
3. **总体时间序列风控**：
   - 波动率 `F_VIX` 与最大回撤 `F_MAXDOWN`
   - 步骤：先按每日资产净值加权得到“全池每日总体收益率时间序列”，再对此序列求 `STDDEV() * SQRT(250)`。
