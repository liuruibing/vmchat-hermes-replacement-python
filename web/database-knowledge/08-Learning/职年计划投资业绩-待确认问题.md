## 3. 我真正需要记住的内容 (Top 5)
1. 冲突不能被静默修改或删除，必须同时保留双方证据与处理建议。
2. 实际业务计算以 E2 源码代码为准，建表注释仅作为 E3 辅助参考。
3. 企年历史 Bug 与特例硬编码不得外推至职年全部数据。
4. 无显式外键不影响逻辑 JOIN，但在表卡片中必须如实标明。
5. 所有未关闭的问题统筹登记在 `99-Inbox/`。
