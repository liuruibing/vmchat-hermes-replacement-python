## 3. 手算例检验与计算示范

### 算例 1：标准现金流日收益率
- 上一日净值 $Nav_{prev} = 100$ 万元，当日申购流入 $IN = 20$ 万元，期末资产净值 $Nav_t = 125$ 万元（无流出）：
  $$\text{真实纯收益} = 125 - 100 - 20 = 5\text{ 万元}$$
  $$R_2 = \frac{5}{100} = \mathbf{5.00\%}$$

### 算例 2：业绩报酬 BP 换算
- 前一日资产净值 20 亿元，受托报酬 $STBC = 4$ 万元，投管报酬 $TGBC = 16$ 万元：
  $$\text{日影响率} = \frac{40,000 + 160,000}{2,000,000,000} = 0.00010 \implies \mathbf{1.00\text{ BP}}$$

## 4. 我真正需要记住的内容 (Top 5)
1. 表画像约束需区分数据库显式约束与候选逻辑键：只有 `MPRF_F_PLAN_DAYNETVALUE` 存在显式 PK `(VC_PLANCODE, D_DATE)`。
2. 收益率必须剔除申购资金 $IN$ 并加回赎回资金 $OUT$。
3. `TCZ` 的代码真实过滤逻辑是 `VC_NAME_GLR LIKE '太平养老保险股份有限公司%'`。
4. 业绩报酬在持仓明细表中的证券代码为 `221002`（受托）和 `220602`（投管）。
5. 跨计划合计行波动率不能直接求平均 `AVG()`，必须对全池总体日收益序列计算 `STDDEV() * SQRT(250)`。
