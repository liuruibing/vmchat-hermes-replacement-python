# 学习卡：职年计划投资业绩 - 10 分钟快速理解指南

本文档专为快速了解“职业年金计划投资业绩”业务与数据架构的新人打造，只覆盖 5–10 张最关键的核心表、指标与规则。

---

## 1. 生活化模型：超市与专柜
- **计划 (Plan)** = **大型超市**（如“上海市职业年金计划”），顶层管理单元。对应维表 [`MDIM_PLAN_INFO`](../04-Tables/MDIM_PLAN_INFO.md)。
- **组合 (Fund)** = **超市里的各个独立专柜**（如“股票专柜”），实际交易与核算单元。对应维表 [`MDIM_FUND_INFO`](../04-Tables/MDIM_FUND_INFO.md)。

## 2. 两个源头科目：701A 与 702A
- **`701A` (资产净值)**：专柜里货物的**总价值**（规模），用作大资金池加权权重。对应底层表 [`MFACTGZ_FUND_HLDTOTAL`](../04-Tables/MFACTGZ_FUND_HLDTOTAL.md)。
- **`702A` (单位净值)**：专柜商品的**单价**（例如 1.05 元），衡量纯单价变动。

## 3. 标准现金流收益率要点
- 计算日收益率 $R_t$ 时，必须扣除当天客户存入的新钱（流入 `IN`），并加回拿走的钱（流出 `OUT`）：
  $$R_t = \frac{Nav_t - Nav_{prev} - IN + OUT}{Nav_{prev}}$$

## 4. 关键规则与 SQL 黑科技
- **TCZ 口径**：实际代码逻辑为“剔除投资管理人为太平养老的组合”。
- **SQL 对数连乘**：SQL 没有连乘聚合函数，程序员利用 $\prod a_i = 2^{\sum \log_2 a_i}$，写作 `POWER(2, SUM(LOG(2, R + 1))) - 1`。

---

## 5. 我真正需要记住的内容 (Top 5)
1. 认准底层源头科目：`701A` 规模，`702A` 单价。
2. 资金流 `IN` 必须扣除、`OUT` 必须加回，否则收益率会被误算。
3. `TCZ` 的代码真实过滤逻辑是 `VC_NAME_GLR LIKE '太平养老保险股份有限公司%'`。
4. 前端 SQL “合计行 (RK=999)” 是多算法混合加权，波动率必须用全池总体日收益序列求标准差。
5. 大宽表 `MPRF_F_PLAN_DAYNETVALUE` 的联合主键为 `(VC_PLANCODE, D_DATE)`。
