# 指标卡：最大回撤 (Max Drawdown)

## 1. 指标定义与时间粒度
- **业务含义**：在指定时间窗口内，资产净值或累计收益率从峰值顶点回落到最低谷底的最大跌幅百分比（符合年金监管 14 号文规范）。
- **时间粒度**：月度 (`F_MMAXDRAW_DAY`)、本年 (`F_YMAXDRAW_DAY`)、成立以来 (`F_CMAXDRAW_DAY`)。

## 2. 输出表与物理字段
- **风险统计表**：`DD_DW.MMON_F_RISK_INDICATORS`
- **输出字段**：`F_MMAXDRAW_DAY` (日收益率回撤-14号文), `F_MMAXDRAW_ACC` (累计收益率回撤)

## 3. 计算公式
$$\text{Drawdown}_t = \frac{\max_{\tau \le t}(Nav_\tau) - Nav_t}{\max_{\tau \le t}(Nav_\tau)}$$
$$\text{Max Drawdown} = \max_t (\text{Drawdown}_t)$$
