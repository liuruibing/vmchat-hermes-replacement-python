# 指标卡：夏普比率 (Sharpe Ratio)

## 1. 指标定义与时间粒度
- **业务含义**：衡量计划或组合每承担一单位总风险所换取的超额投资回报。
- **时间粒度**：月度 (`F_MSHARP`)、本年 (`F_YSHARP`)、成立以来 (`F_CSHARP`)。

## 2. 输出表与物理字段
- **风险统计表**：`DD_DW.MMON_F_RISK_INDICATORS`
- **输出字段**：`F_MSHARP`, `F_YSHARP`, `F_CSHARP`

## 3. 计算公式
$$\text{Sharpe Ratio} = \frac{R_p - R_f}{\sigma_p}$$
其中 $R_p$ 为年化收益率，$R_f$ 为无风险利率（选取一年期定存 benchmark 代码 `104CNY`），$\sigma_p$ 为年化波动率。
