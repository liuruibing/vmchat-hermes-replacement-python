# 指标卡：标准现金流收益率 (Standard Cash Flow Yield)

## 1. 指标定义与时间粒度
- **业务含义**：剔除当日申购资金（流入 `IN`）与赎回资金（流出 `OUT`）干扰后的真实日投资收益率。
- **时间粒度**：交易日日收益率 ($R_t$)、区间交易日连乘累计收益率。

## 2. 输出表与物理字段
- **结果大宽表**：`DD_DW.MPRF_F_PLAN_DAYNETVALUE`
- **核心字段**：
  - `F_DP_YIELD_BZ`：标准现金流日收益率
  - `F_PLAN_YIELD_TBZ`：标准现金流交易日成立以来累计收益率
  - `F_PLAN_YIELD_TBZ_YEAR`：标准现金流交易日本年以来累计收益率

## 3. 计算公式与 SQL 表达式
- **日收益率公式**：
  $$R_t = \frac{Nav_t - Nav_{prev} - IN_t + OUT_t}{Nav_{prev}}$$
- **对数连乘 SQL 表达式**：
  ```sql
  POWER(2, SUM(LOG(2, F_DP_YIELD_BZ + 1))) - 1
  ```
