# 指标卡：剔除太平养老组合收益率 (TCZ Yield)

## 1. 指标定义与时间粒度
- **业务含义**：在职业年金计划层面，排除由“太平养老保险股份有限公司”担任投资管理人的组合后，剩余组合汇总的标准现金流收益率。
- **时间粒度**：日度、区间连乘累计。

## 2. 输出表与物理字段
- **结果大宽表**：`DD_DW.MPRF_F_PLAN_DAYNETVALUE`
- **核心字段**：
  - `F_DP_YIELD_BZ_TCZ`：标准现金流日收益率（剔除太平组合）
  - `F_PLAN_YIELD_TBZ_TCZ`：成立以来累计收益率（剔除太平组合）

## 3. 计算公式与代码过滤逻辑
- **源码过滤条件 (E2 确认)**：
  ```sql
  -- 排除投资管理人为太平养老的组合
  WHERE MDIM_FUND_INFO.VC_NAME_GLR LIKE '太平养老保险股份有限公司%'
  ```

## 4. 冲突与避坑提示
- **缩写冲突**：建表注释描述为“剔除支付组合”，但代码实际逻辑为“剔除太平养老组合”（详见 [`CONF-001`](../99-Inbox/Conflicts.md#conf-001) 和 [`07-Rules/TCZ-剔除太平养老管理组合.md`](../07-Rules/TCZ-剔除太平养老管理组合.md)）。
- **企年错调 Bug**：企业年金存储过程存在未生效 TCZ 剔除的历史 Bug（详见 [`CONF-002`](../99-Inbox/Conflicts.md#conf-002)）。
