# 指标卡：单位净值增长率 (NAV Growth Rate)

## 1. 指标定义与时间粒度
- **业务含义**：衡量单份年金基金单位在特定区间内的单价涨跌幅度（`702A` 科目），不受大额资金申赎平摊影响。
- **时间粒度**：日度、区间累计。

## 2. 输出表与物理字段
- **结果宽表**：`DD_DW.MPRF_F_PLAN_DAYNETVALUE`
- **输出字段**：`RYIELDG` (前端 SQL 加权输出), `F_UNITVALUE`

## 3. 计算公式
$$\text{日单位净值增长率} = \frac{Nav\_Unit_t - Nav\_Unit_{prev}}{Nav\_Unit_{prev}}$$
其中 $Nav\_Unit$ 对应 `MFACTGZ_FUND_HLDTOTAL` 中 `VC_SUBCODE = '702A'` 的 `F_PRICE`。

## 4. 前端 SQL 汇总规则
- 在前端查询 `RK=999` 合计行中，采用期末资产净值进行加权平均：
  ```sql
  SUM(RYIELDG * F_NETVALUE) / SUM(F_NETVALUE)
  ```
