# 指标卡：年化波动率 (Annualized Volatility / Vix)

## 1. 指标定义与时间粒度
- **业务含义**：测量收益率序列偏离均值的离散程度，用以评估资金池的收益波动风险。
- **时间粒度**：月度 (`F_MVIX`)、本年 (`F_YVIX`)、成立以来 (`F_CVIX`)。

## 2. 输出表与物理字段
- **风险统计表**：`DD_DW.MMON_F_RISK_INDICATORS`
- **输出字段**：`F_MVIX` (月度波动率), `F_YVIX` (本年波动率), `F_CVIX` (成立以来波动率)

## 3. 计算公式与跨计划聚合规则
- **单计划公式**：`STDDEV(R_t) * SQRT(250)`
- **前端 SQL 跨计划合计行规则 (核心避坑)**：
  **禁止**直接取 `AVG(F_VIX)`；必须先按每日资产净值加权计算全池“总体日收益率序列”，再对此总体序列求标准差并乘以 $\sqrt{250}$。
