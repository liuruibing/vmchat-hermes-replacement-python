# 指标卡：投管业绩报酬 (TGBC - Investment Manager Fee)

## 1. 指标定义与时间粒度
- **业务含义**：职业年金各投资组合计提的投资管理业绩报酬金额。
- **时间粒度**：日度汇总切片。

## 2. 输出表与物理字段
- **结果大宽表**：`DD_DW.MPRF_F_PLAN_DAYNETVALUE`
- **核心字段**：`F_PLAN_TGBC`（投管业绩报酬计提金额）

## 3. 提取公式与底层证券代码 (E2 确认)
- 汇总持仓明细表 `MFACTGZ_FUND_HLDDETAIL` 中证券代码 **`VC_SYMBOL = '220602'`** 的市值 `F_PRICE`：
  ```sql
  SELECT NVL(SUM(T.F_PRICE), 0)
  FROM MFACTGZ_FUND_HLDDETAIL T
  WHERE T.VC_SYMBOL = '220602'
    AND T.D_DATE >= TO_DATE(I_STARTDATE, 'YYYY-MM-DD')
    AND T.D_DATE <= TO_DATE(I_ENDDATE, 'YYYY-MM-DD');
  ```
