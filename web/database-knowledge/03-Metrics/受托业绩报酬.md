# 指标卡：受托业绩报酬 (STBC - Trustee Performance Fee)

## 1. 指标定义与时间粒度
- **业务含义**：职业年金计划层面计提的受托管理服务报酬金额。
- **时间粒度**：日度汇总切片。

## 2. 输出表与物理字段
- **结果大宽表**：`DD_DW.MPRF_F_PLAN_DAYNETVALUE`
- **核心字段**：`F_PLAN_STBC`（受托业绩报酬计提金额）

## 3. 提取公式与底层证券代码 (E2 确认)
- 汇总持仓明细表 `MFACTGZ_FUND_HLDDETAIL` 中证券代码 **`VC_SYMBOL = '221002'`** 的市值 `F_PRICE`：
  ```sql
  SELECT SUM(F_PRICE) 
  FROM MFACTGZ_FUND_HLDDETAIL 
  WHERE VC_SYMBOL = '221002' AND D_DATE = :current_date
  ```
