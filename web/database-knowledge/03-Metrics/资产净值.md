# 指标卡：资产净值 (Net Asset Value / Scale)

## 1. 指标定义与时间粒度
- **业务含义**：计划或组合在特定核算日期的资产总净值。
- **时间粒度**：日粒度（每个交易日/自然日）。

## 2. 输出表与物理字段
- **结果宽表**：`DD_DW.MPRF_F_PLAN_DAYNETVALUE`
- **输出字段**：`F_NETVALUE`（计划资产净值）, `F_NETVALUE_TCZ`（剔除太平净值）

## 3. 计算公式与 SQL 表达式
- **底层公式**：汇总下属所有有效组合在特定日期的 `701A` 科目市值。
- **存储过程片段**：
  ```sql
  -- DW_ZNST_INDEX_NEW 汇总逻辑
  SUM(MFACTGZ_FUND_HLDTOTAL.F_PRICE) WHERE VC_SUBCODE = '701A'
  ```

## 4. 前端 SQL 汇总与常用规则
- 前端 `RK=999` 合计行采用 `SUM(F_NETVALUE)` 对全选计划直接累加求和。
