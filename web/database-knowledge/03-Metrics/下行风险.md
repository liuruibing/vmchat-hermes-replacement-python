# 指标卡：下行风险 (Downside Risk / Vix Desc)

## 1. 指标定义与时间粒度
- **业务含义**：仅对收益率低于无风险利率（如 104CNY 规则）的负偏离日收益率序列求波动率，用以衡量投资者面临的实际亏损风险。
- **时间粒度**：月度 (`F_MVIX_DESC`)、本年 (`F_YVIX_DESC`)、成立以来 (`F_CVIX_DESC`)。

## 2. 输出表与物理字段
- **风险统计表**：`DD_DW.MMON_F_RISK_INDICATORS`
- **输出字段**：`F_MVIX_DESC`, `F_YVIX_DESC`, `F_CVIX_DESC`

## 3. 计算公式要点
- 只关注小于基准利率 $R_f$ 的样本点，剔除上涨离散度的影响。
