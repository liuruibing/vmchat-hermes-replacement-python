# 指标卡：业绩报酬影响 (Fee Impact in BP)

## 1. 指标定义与时间粒度
- **业务含义**：受托业绩报酬与投管业绩报酬总额占前一日资产净值的比例，在 SQL 展示层转换为 **BP (基点/万分比)**。
- **时间粒度**：日度切片。

## 2. 输出表与物理字段
- **结果大宽表**：`DD_DW.MPRF_F_PLAN_DAYNETVALUE`
- **核心字段**：`F_PLAN_YJBCYX`（业绩报酬影响，BP）

## 3. 计算公式 (E1 / E2 确认)
$$\text{日影响率} = \frac{\text{STBC} + \text{TGBC}}{\text{前一日计划资产净值}}$$
在前端查询 SQL 中乘以 **10000** 转换为 BP 展示：
$$\text{展示值 (BP)} = \text{日影响率} \times 10000$$
