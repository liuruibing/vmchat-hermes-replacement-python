# DBX + AI Agent 数据库业务知识研究工作流

本文档固化 AI Agent 与研究人员在知识库增量探查、元数据验证、血缘梳理及卡片编写时的标准工作流程与契约约束。

---

## 1. 八步标准研究流程

每次研究新对象、新表或新指标时，必须严格按以下顺序执行，**严禁跳过任何步骤**：

```text
[1. 读取知识库 & 证据索引]
         │
         ▼
[2. 提取候选对象 / 指标 / 表]
         │
         ▼
[3. DBX dbx_list_connections 校验连接]
         │
         ▼
[4. DBX dbx_describe_table 校验字段 / 注释 / 显式约束]
         │
         ▼
[5. DBX dbx_execute_query (ROWNUM <= 20) 只读探查 / 聚合分布]
         │
         ▼
[6. 交叉检索 SQL / 存储过程源码与 E1 业务文档]
         │
         ▼
[7. 写入 09-Evidence 生成新证据档案]
         │
         ▼
[8. 生成/更新知识卡片 & 运行冲突检查]
```

### 禁忌与原则
- **绝对禁止**仅凭表名、字段名拼写（如 `VC_TYPE_IN`）或前 5 行数据形状直接裁定业务含义。必须依靠规范的 E1（文档）、E2（源码）或 E3（元数据）提供证据。
- **绝对禁止**通过开发版 CLI、本地驱动或脚本绕过 DBX MCP 工具直连数据库。
- **绝对禁止**将推断（I）擅自升级为已确认（confirmed）。

---

## 2. DBX MCP 工具使用契约

研究过程中必须使用注册的 DBX MCP 工具（全局配置于 `~/.codex/config.toml`）：

1. **`dbx_list_connections`**:
   - 用途：列出当前可用数据库连接。确认 `connection_name: "DD_AODS"` 可用。
2. **`dbx_list_tables`**:
   - 用途：按 Schema 检索表清单。`schema_name` 可为 `DD_DW`、`DD_AODS` 等。
3. **`dbx_describe_table`**:
   - 用途：查询指定表的列名、数据类型、注释及数据库显式 constraints/indexes。
4. **`dbx_get_schema_context`**:
   - 用途：获取 Schema 整体上下文结构。
5. **`dbx_execute_query`**:
   - 用途：执行**单条只读** SELECT 查询。
   - 限制：`connection_name` 固定为 `"DD_AODS"`；查询必须显式指定 `WHERE ROWNUM <= 20`（达梦/Oracle）或 `LIMIT 20`；不允许多语句拼接；严禁包含写操作关键字。

## 3. 各类知识卡片的最小必填章节

### 3.1 表卡片 (`04-Tables/*.md`) 最小内容
- 一行描述：该表代表什么业务实体
- 粒度（Grain）：一行记录对应什么（如：一个组合在某一交易日的核算快照）
- 数据库显式主键与唯一约束（严禁把普通索引当作主键；无显式约束时标明“无显式主键”）
- 核心字段分组列表（身份与名称、计划归属、生命周期、核算金额、审计字段等）
- 样例数据（包含 `ROWNUM <= 20` 的脱敏样例）
- 上游与下游关联表（常用 JOIN 键及条件）
- 待确认与开放问题（无法由 E1-E4 确认的疑点）

### 3.2 指标卡片 (`03-Metrics/*.md`) 最小内容
- 归属业务对象与输出字段
- 时间粒度与业务含义
- 核心计算公式（数学公式及 SQL/存储过程表达式）
- 输入表/字段与输出表/字段
- 过滤条件与聚合逻辑
- 适用场景与常见误区
- 证据链（链接至 `09-Evidence/`）

### 3.3 血缘卡片 (`05-Lineage/*.md`) 最小内容
- 表级链路图与字段级依赖关系
- 每一步的转换逻辑、过滤条件及时间口径
- 验证 SQL（可重复执行的只读验证 SQL）
- 尚未证实的链路段（标注 **I** 或链接至 `Open-Questions.md`）

### 3.4 规则卡片 (`07-Rules/*.md`) 最小内容
- 规则标准文本描述
- 影响的业务指标与关联字段/存储过程函数
- 支持规则的 E1/E2 证据引用
- 规则的有效范围与历史冲突点说明

### 3.5 学习卡片 (`08-Learning/*.md`) 最小内容
- 目标与前置知识要求
- 核心逻辑精炼讲解（仅引用 `confirmed` / `supported` 知识）
- 末尾固定章节：“我真正需要记住的内容”（最多 5 条）
- 末尾固定章节：“待确认问题与延伸思考”
