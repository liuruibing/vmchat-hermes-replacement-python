3. SQL 合计行四种汇总口径对比

汇总口径分类对应输出指标具体计算与加权逻辑
1. 期末净值加权 RYIELDG, F_PYEILD_QJ_TCTP 按区间结束日 F_NETVALUE 资产净值比例加权汇总各计划收益率
2. 总体加权收益函数 MYIELDG, YYIELDG, CYIELDG 调用 GET_OVERALL_WEIGHTED_RETURN_R/W，前一自然日 701A 加权 702A 增长率几何连乘
3. 逐日净值加权序列 F_VIX, F_MAXDRAW_DAY, F_SHARP 先按每日净值加权生成总体日收益率序列，再计算波动率、14号文回撤与夏普

4. 关键疑点与口径避坑指南

TCZ 口径: TCZ 实际为“剔除太平养老管理组合” (VC_NAME_GLR LIKE '太平养老保险%')，非字面“剔除支付组合”。
企年错调: 企年 F_DP_YIELD_BZ_TCZ 源码误调用了未剔除 TCZ 的 F_PLAN_DYIELD_BZ，属于复制错误。
1105 硬编码: 职年计划 1105 在 2019-08-02/03 两天存在 0 与 0.000007967 的硬编码强制覆盖。
14号文回撤: F_MAXDRAW_DAY 为日收益率前高后低差 (G-K)/(G+1) 的最大值，非常规净值曲线回撤。
