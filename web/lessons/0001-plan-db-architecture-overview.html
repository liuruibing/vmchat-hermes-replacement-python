单元 1：职年/企年计划数据库 5 层血缘模型

在养老金投资管理业务中，职年（职业年金）与企年（企业年金）计划的收益率与风险指标计算链路非常长。为了能够独立排查数据异常与核对指标，我们必须首先掌握从原始流水表到SQL 最终输出指标的 5 层数据血缘模型。

知识精讲：数据血缘的 5 个层级

来源：职年计划查询SQL_字段计算逻辑分析.md 来源：字段级清洗逻辑总表.md

1. 源数据与维表层 (Source & Dimension Layer)

包含估值流水表 MFACTGZ_FUND_HLDTOTAL（科目 701A 汇总组合资产规模）、资金流流水 ASSETINOUT、持仓明细 HLDDETAIL（证券代码 221002/220602 汇总报酬）以及计划/基金维表 MDIM_PLAN_INFO 等。

2. 清洗与计算函数层 (ETL & Calculation Layer)

由 DW_ZNST_INDEX_NEW（清洗日净值与现金流）、DW_ZNST_INDEX_ADD（计算累计收益）、PKG_DW_OPERATION.F_YIELD_GROUP（单计划收益率）及 GET_OVERALL_WEIGHTED_RETURN_R/W（总体加权函数）组成。

3. 核心计划日数据层 (Core DW Layer)

核心 DW 表 MPRF_F_PLAN_DAYNETVALUE，汇总落库每日计划资产净值、现金流、标准/不标准日收益率及业绩报酬。

4. 职年计划查询 SQL 计算层 (SQL Aggregation Layer)

SQL 采用 UNION ALL 结构：单计划明细行按期末净值降序排名；合计行采用期末净值加权、总体加权收益函数、逐日净值加权序列算风险及历史风险指标直读四种不同汇总口径。

5. 输出指标层 (Output Metrics Layer)

划分为四大输出指标组：基础信息与净值组、收益率指标组 (RYIELDG/MYIELDG 等)、业绩报酬组 (STBC/TGBC/JHBCYX) 及风险指标组 (F_VIX/14号文回撤/夏普/MMON直读)。
