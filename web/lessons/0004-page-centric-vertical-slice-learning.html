单元 4：以“职年计划查询页面”为核心的垂直切片学习法

非常赞同你的学习思路！“以具体页面为核心，找一个页面吃透它背后的 SQL 和业务逻辑”是金融与企业级系统开发中最实用的垂直切片学习法 (Vertical Slice Learning)。

来源：职年计划查询SQL_字段计算逻辑分析.md

页面 ↔ SQL ↔ DW 垂直切片 4 层映射模型

📌 1. 页面前端筛选条件 ➔ SQL WHERE 过滤映射
前端页面控件传递参数对应查询 SQL 的 WHERE 过滤逻辑
开始日期 / 结束日期 beginDate / endDate D_CREATE_DATE <= endDate AND D_END_DATE >= beginDate
区间开始日 D_SDATE = beginDate，区间结束日 D_EDATE = endDate
计划类型下拉框 VC_PTYPE VC_TYPE_DETAIL='ZYNJ' (固定职年)
若传入 VC_PTYPE，增加 AND VC_PLAN_TYPE = :VC_PTYPE 过滤
📌 2. 页面表格行结构 ➔ SQL UNION ALL 结构映射
页面表格展现SQL 实现逻辑RK 排名列与固定列处理
顶部：单计划明细行
(每个计划单独一行)		 SQL 上半段：以计划为维度 GROUP BY，按期末资产净值 F_PNETVALUE 降序排列 RK 列取 ROW_NUMBER() OVER(ORDER BY F_PNETVALUE DESC)；
PLANCODE 取 VC_PLAN_LIC_ID，PLANNAME 取计划全称。
底部：固定“合计”行
(符合条件计划汇总为一行)		 SQL 下半段：UNION ALL，所有计划汇总成单行 RK 内部赋值 999，最外层 DECODE(999,999,NULL,999) 渲染为空；
PLANCODE='ZYNJ'，PLANNAME='合计'。
📌 3. 页面表格列指标 ➔ 四种计算口径与 DW 函数映射
页面表格列名单计划明细行计算逻辑合计行计算逻辑 (4种汇总口径)
资产净值 F_NETVALUE 取结束日科目 701A 的有效组合净值 所有符合条件计划期末资产净值的直接求和 SUM(F_PNETVALUE)
区间收益率 RYIELDG DW 表日收益率在区间内的几何连乘 ∏(1+r_t)-1 口径1 (期末加权): 按各计划期末资产净值 F_PNETVALUE 比例加权汇总
月度收益率 MYIELDG 月初 TRUNC(endDate,'MM') 至结束日的几何连乘 口径2 (总体加权函数): 调用 GET_OVERALL_WEIGHTED_RETURN_W 规模加权连乘
日波动率 F_VIX 直接调用单计划收益率序列计算年化标准差 口径3 (逐日加权序列): 先按每日净值生成总体加权序列 r̄_t，再计算标准差
本年/成立风险指标 从 MMON_F_RISK_INDICATORS 直读 口径4 (历史直读): SQL 现场不计算，直接读取存量表 MMON
📌 4. 页面吃透法实战 3 步建议
  1. 看渲染取数：打开“职年计划综合查询”页面，按 F12 抓取请求参数（beginDate, endDate, VC_PTYPE）。
  2. 看表头对 SQL 列：将表格的 `RK` / `PLANNAME` / `RYIELDG` / `STBC` / `F_VIX` 与 SQL 查询列名一一比对。
  3. 看合计行排查疑点：检查页面合计行的收益率与波动率，确认其调用的总体加权函数与逐日加权序列，并高亮 TCZ 剔除太平养老口径与 1105 硬编码等特例。
